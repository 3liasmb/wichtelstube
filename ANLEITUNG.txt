WICHTELSTUBE – GitHub Pages

1. Neues öffentliches Repository auf GitHub anlegen, z.B. wichtelstube.
2. Alle Dateien (index.html, app.css, core.js, app.js, sw.js, manifest.webmanifest) und den Ordner icons ins Repository-Hauptverzeichnis hochladen. Der Ordner tests wird für die App nicht benötigt.
3. Settings > Pages > Build and deployment: Deploy from a branch, Branch main, Folder /(root), Save.
4. Die von GitHub angezeigte HTTPS-Adresse in Safari auf dem iPhone öffnen.
5. Teilen > Zum Home-Bildschirm.
6. Mit Fantasienamen Sicherung, Import und Drucken auf iPhone testen.

Wichtig: Repository öffentlich = Programmcode öffentlich, nicht die lokal eingegebenen Schülerdaten. Keine Schülerlisten oder Sicherungen ins Repository hochladen.

Bei jeder neuen Version: VERSION in sw.js und alle ?v= in index.html erhöhen (siehe README.md).
